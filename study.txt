0단계를 완료했으니 이제 다음 순서로 공부하면 됩니다.

## 1단계: 그래프 탐색

```text
Graph 표현
→ BFS
→ DFS
→ 경로 존재 여부
→ 연결 요소
→ 경로 복원
→ 무가중치 최단 거리
→ 사이클 탐지
→ 위상 정렬
```

### 1. Graph 표현

현재 만든 `Graph<T>`를 사용합니다.

- 인접 리스트
- 방향 그래프와 무방향 그래프
- 정점·간선 추가 및 삭제
- 정점 수와 간선 수 관리

### 2. BFS

큐를 사용하는 너비 우선 탐색입니다.

```csharp
List<T> BFS(T start)
```

- 가까운 정점부터 탐색
- 무가중치 그래프의 최단 거리 계산 가능
- 시간 복잡도: `O(V + E)`
- 공간 복잡도: `O(V)`

### 3. DFS

스택 또는 재귀를 사용하는 깊이 우선 탐색입니다.

```csharp
List<T> DFS(T start)
```

두 가지 방식을 모두 구현하는 것이 좋습니다.

```text
RecursiveDFS
IterativeDFS
```

- 연결 요소 탐색
- 사이클 탐지
- 위상 정렬의 기반
- 시간 복잡도: `O(V + E)`
- 공간 복잡도: `O(V)`

### 4. 경로 존재 여부

```csharp
bool HasPath(T start, T destination)
```

BFS 또는 DFS로 목적지에 도착할 수 있는지 확인합니다.

### 5. 연결 요소

```csharp
List<List<T>> FindConnectedComponents()
```

무방향 그래프에서 서로 연결된 정점들을 그룹으로 분리합니다.

### 6. 경로 복원

```csharp
List<T>? FindPath(T start, T destination)
```

탐색할 때 각 정점의 이전 정점을 기록하고 목적지부터 역추적합니다.

### 7. 무가중치 최단 거리

```csharp
int GetShortestDistance(T start, T destination)
List<T>? FindShortestPath(T start, T destination)
```

조건:

- 가중치가 없거나 모든 간선 가중치가 동일해야 함
- BFS를 사용해야 최단 거리가 보장됨

### 8. 사이클 탐지

```text
UndirectedCycleDetection
DirectedCycleDetection
```

- 무방향 그래프: 이전 정점과 다음 정점을 구분
- 방향 그래프: 방문 전·탐색 중·완료의 3가지 상태 사용

### 9. 위상 정렬

두 가지 방법을 구현하세요.

```text
Kahn 알고리즘: 진입 차수 + Queue
DFS 방식: 방문 상태 + Stack
```

조건:

- **방향성 비순환 그래프(DAG)**에서만 가능
- 사이클이 있다면 위상 정렬할 수 없음

## 2단계: 가중 그래프와 최단 경로

```text
WeightedGraph
→ Dijkstra
→ Bellman-Ford
→ Floyd-Warshall
→ A*
```

### 구현 순서

1. `WeightedEdge<T>`
2. `WeightedGraph<T>`
3. Dijkstra
4. Bellman-Ford
5. Floyd-Warshall
6. A*

조건:

- Dijkstra: 음수 가중치 사용 불가
- Bellman-Ford: 음수 가중치 가능, 음수 사이클 탐지 가능
- Floyd-Warshall: 모든 정점 쌍의 최단 거리
- A*: 목적지까지의 예상 비용을 계산하는 휴리스틱 필요

Unity에서는 Dijkstra 다음에 A*를 중점적으로 공부하세요.

## 3단계: 최소 신장 트리

```text
Kruskal
→ Prim
```

### Kruskal

- 간선을 가중치순으로 정렬
- `UnionFind`로 사이클 방지
- 무방향 가중 그래프에서 사용

### Prim

- `MinPriorityQueue` 사용
- 하나의 정점에서 트리를 확장
- 연결되지 않은 그래프에서는 최소 신장 포리스트가 필요

## 4단계: 알고리즘 설계 유형

```text
재귀
→ 분할 정복
→ 그리디
→ 백트래킹
→ 동적 계획법
```

대표 구현:

- 재귀: 팩토리얼, 하노이 탑
- 분할 정복: 빠른 거듭제곱
- 그리디: 회의실 배정, 동전 선택
- 백트래킹: 순열, 조합, N-Queen
- 동적 계획법: Fibonacci, Knapsack, LCS, 격자 경로

---

## 5단계: 문자열

```text
문자열 직접 비교
→ Trie
→ KMP
→ Rabin-Karp
```

- Trie: 접두사 검색과 자동완성
- KMP: 접두사·접미사 정보를 이용한 문자열 검색
- Rabin-Karp: 해시를 이용한 문자열 검색

---

## 6단계: 추가 정렬과 탐색

```text
Counting Sort
→ Radix Sort
→ Quick Select
→ Lower Bound
→ Upper Bound
```

조건:

- Counting Sort: 정수 값의 범위가 제한적이어야 함
- Radix Sort: 각 자릿수를 안정 정렬해야 함
- Quick Select: 평균 `O(n)`, 최악 `O(n²)`
- Lower/Upper Bound: 배열이 정렬되어 있어야 함

지금 바로 시작할 정확한 순서는 다음입니다.

```text
BFS
→ 반복형 DFS
→ 재귀형 DFS
→ HasPath
→ 연결 요소
→ BFS 경로 복원
→ 무가중치 최단 거리
→ 무방향 사이클 탐지
→ 방향 그래프 사이클 탐지
→ 위상 정렬
```
